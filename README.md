## 🚀 Current Projects

### 🩺 Clinical AI
- **ICD Coding from Discharge Summaries** — end-to-end pipeline for messy EMR exports: cleaning, de-identification, and ICD classification with domain-adaptive pretraining (DAPT)
- **Schistocyte / RBC Morphology Classification** — Cellpose segmentation + RedDino foundation-model embeddings on Chula-RBC-12
  🏆 *Excellence Award, AI in Medicine (AIM) Bootcamp 2026, Universiti Malaya*
- **Microsporidia Detection in Microscopy** — U-Net (ResNet encoder) segmentation and presence/absence detection on stained oil-immersion images, heading toward mobile + web deployment
- **Clinical Dialogue LLM** — LoRA fine-tuning of Llama 3.1 on synthetic doctor–patient conversations *(manuscript under review)*

### 🎓 Medical Education Tech
- [**MED-AI**](https://ukmfperstudentportfolio.streamlit.app/) — app-based workplace-based assessment (Mini-CEX) replacing paper forms for clinical-year students; deployed in Internal Medicine Year 3
  🏆 *kNovasi 2025 winner (UKM level, Alternative Assessment) — invited to national level*
- **Conversational Reflection** — students reflect by chatting with an LLM (few-shot + RAG over rubric and task, optional Whisper voice input), scored against a rubric
- **Smart Question Bank Analytics** — modelling MCQ item difficulty and discrimination from question text
- **Longitudinal Exam Analytics** — automated compilation and analysis of five years of professional exam results

### 🧰 Tools for Researchers & Students
- **Thesis Formatter** — local, no-code thesis editor for the UKM template: Typst rendering, built-in BibTeX manager, EndNote import, Word `.docx` round-trip with tracked changes
- **RCT Manager** — local trial-management app where an LLM builds the study design from natural language but never sees patient data; SQLite, audit trail, GCP-minded
- **Research Collaboration Network** — co-author network and collaborator recommender for UKM Faculty of Medicine staff
- **R for Researchers** — two-day beginner R workshop following *R for Data Science (2e)*, built around a simulated clinical-trial dataset

### 🗂️ Earlier Work
